# pushed from these sessions -- the remote answers 403 to a receive-pack for
# refs/tags/* while branch pushes succeed (Mythos-Core#10 records the same denial
# for v0.2.0 and what a person still needs to do). A commit pin is immutable and
# resolves the same tree. CI needs a MYTHOS_CORE_TOKEN secret to install the
# private dependency, as on the engine repos.
#

# / and the collector answered 404 while tracing_status() reported "spans are
# created and exported". This service binds that tracing, so before the bump its
# telemetry was configured and gone with nothing saying so. The release also
# redacts userinfo out of the endpoint that status block publishes, and bounds
