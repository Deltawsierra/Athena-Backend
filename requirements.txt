# The shared Mythos foundation. The failsafe control plane uses
# mythos_core.failsafe to verify operator command signatures with the SAME
# definition the engine uses, so the two never disagree, and mythos_core.tracing
# for the shared span vocabulary assurance/observability.py binds.
#
# Pinned to a COMMIT rather than a tag: tag refs cannot be pushed from these
# sessions -- the remote answers 403 to a receive-pack for refs/tags/* while
# branch pushes succeed (Mythos-Core#10 records the same denial for v0.2.0 and
# what a person still needs to do). A commit pin is immutable and resolves the
# same tree. CI needs a MYTHOS_CORE_TOKEN secret to install the private
# dependency, as on the engine repos.
#
# What the pins since 539538c (Mythos-Core#23) added:
#
# Mythos-Core#24 -- the control loop died on a hostile command. The failure log
# line evaluated _action_of(command) as an ARGUMENT, so attribute access on the
# command ran outside the guard written to survive it; a .action property raising
# anything but AttributeError unwound the daemon thread. An engine in that state
# can no longer receive the RELEASE that frees it or the TERMINATE that escalates
# a failed stand-down, and ControlLoop has no restart. This service is the control
# plane those commands are drafted and relayed from, so an engine stuck that way
# is an engine its own console cannot reach.
#
# Mythos-Core#25 -- a caller-supplied proxies= walked past _check_proxy. A proxy
# retires both halves of the egress guard (urllib3 hands the proxy a hostname, so
# the approved address is never dialled), and the merge used `or`, so a caller
# dict naming any scheme also suppressed the whole of an operator's mandatory
# proxy configuration while proxy_summary() went on printing it.
#
# Mythos-Core#26 -- four ways a request left safe_http's guard, the control
# channel's ambient-identity lockout among them. This service imports neither
# safe_http nor the control channel; recorded so the next reader need not check.
#
# Mythos-Core#27 -- mythos_core.outcome: one schema, DSSE signature and verifier
# for a chain outcome an engine observed. assurance/observed_outcomes.py verifies
# every signed outcome with it, at ingest and again at every read.
#
# Mythos-Core#28 -- a small-order Ed25519 key verifies one constant signature for
# every message, so a keyring holding one returned any typed-in outcome as
# authentic. TrustedKey now refuses small-order, off-curve and non-canonical keys
# at construction -- the keyring this service loads is built from TrustedKeys --
# the signed payload must be the canonical encoding of what it parses to, and the
# named engine must equal the key's exactly.
#
# Mythos-Core#29 -- documentation only: a signed held establishes which engine
# said so and when, not that the effect happened. assurance.composition reads an
# Achilles held as an authorization check for exactly that reason.
#
# Mythos-Core#30 -- a URL whose host no parser can read is refused by the egress
# guard with the parser's reason instead of raising. This service did not import
# the egress guard until the #47 pin below; its target guard now asks it.
#
# Mythos-Core#31 -- mythos_core.evidence holds the evidence-class table: the rank
# of each class, its ordinal strength, its qualitative reading and CLASS_BASIS.
# This service computed a claim's confidence and ranked evidence classes with a
# copy of its own; it reads all of them from that table now (roadmap P2.7:
# assurance/claim_confidence.py, assurance.models.evidence_strength), and the
# assurance policy pins the table's order of the classes.
#
# Mythos-Core#32, #33, #36 -- failsafe fixes on the engine side: the control poll
# reaches a control plane on a private address, a terminate's attestation leaves
# and nothing waits on it, and every stand-down (not only the first) drops the
# engine's footholds. This service runs no Governor and no control loop; it
# drafts and relays the commands those engines obey.
#
# Mythos-Core#34 -- a public key no private key stands behind (small-order,
# mixed-order, off the curve or non-canonical) is refused wherever one is
# loaded, mythos_core.keycheck. TrustedKey is one of those places, so the outcome
# keyring assurance/observed_outcomes.py loads refuses a mixed-order key as well.
#
# Mythos-Core#35 -- documentation only: the owner's written freeze exceptions.
#
# What the pin since c3c6c19 (Mythos-Core#36) adds:
#
# Mythos-Core#47 -- the reason for the b3fef5f pin: resolver equivalence. The egress
# policy decides on the host in the form the HTTP client dials
# (egress.resolver_host, urllib3's own reader: lowercased, percent-escapes
# decoded, IDNA 2008, no root dot), refuses a URL the client cannot read (a
# port out of range, `:+80`, a non-ASCII digit, fullwidth letters, ideographic
# dots, a malformed escape, `http:host` with no authority), and drops an IPv6
# zone ID before its metadata check; the authority scope's normalise_host uses
# the same reader. Its decide/connect map named two places in this service that
# decided destinations their own way, and both now ask core:
# pentest/views.py target_is_out_of_bounds decides through egress.check_target
# (no name list of its own compared as written, no IDNA 2003 getaddrinfo of its
# own), refuses a URL whose host as written is not the host the client dials,
# and still holds every approved address to this service's internal-network
# list; pentest/models.py Engagement.covers reduces both sides with
# normalise_host, and covers a host only where it did before AND in the
# dialled form. Both only tighten
# (tests/test_the_target_guard_decides_on_the_host_the_client_dials.py runs
# #47's corpus through the guard).
#
# Mythos-Core#41 -- a clock fault never blocks a stop: an engine applies a PAUSE
# or STAND_DOWN outside its validity window and records where its clock stood;
# RESUME, RELEASE and TERMINATE keep the window. This service drafts and relays
# those commands (failsafe/) and runs no Governor; what it signs is unchanged,
# and tests/test_failsafe_control_plane.py verifies them with this pin's
# verify_command. #42 adds a test of the same rule.
#
# Mythos-Core#40 -- the chain verifiers never write to what they verify, and an
# empty chain reads empty, not ok. #39 -- mythos_core.recovery, a restore
# drill. This service calls neither. #37 and #38 are documentation and tests;
# #43 (a secret-scan CI gate), #44 and #46 (FREEZE.md) carry no code.
#
# What the pin since b3fef5f (Mythos-Core#47) adds:
#
# Mythos-Core#48 -- property tests of the trusted core, and the violations they
# found: a nonce is checked and spent as one step (one signed command on several
# threads is accepted once); a nonce store that cannot be read or written
# refuses a RESUME, RELEASE or TERMINATE and never blocks a PAUSE or
# STAND_DOWN; malformed input is a CommandRejected from verify_command,
# Command.from_dict and Governor.apply, never an exception; Governor keeps an
# empty durable nonce store; the keyring tool exports each key as lowercase
# hex; and safe_http reports a response with invalid framing, or a compressed
# body cut short, as truncated. This service runs no Governor and calls no
# verify_command: it reaches Command.from_dict only to compute a command's
# signing bytes from fields it builds itself (failsafe/signing.py), which are
# well-formed, so nothing it sends or verifies changes. It exports no keyring
# with the tool and makes no safe_http request.
# tests/test_failsafe_control_plane.py verifies what it signs with this pin's
# verify_command.
